# Gaze

一款本地漫画阅读器。读第 50 页就只解压第 50 页 —— 几百 MB 的合集包不必先展开到缓存，
翻开就能看。扫描、整理、阅读全部在设备上完成。

**不需要账号，不需要服务器，不联网。**

## 主要功能

### 文件格式

- **漫画归档**：CBZ / CBR / CBT / CB7
- **普通压缩**：ZIP / RAR / TAR / 7Z
- **文档**：PDF / EPUB，可直接加入书架阅读
- **页面图片**：JPG / JPEG / PNG / WEBP / GIF（取静态首帧）/ AVIF / BMP / HEIC
- **自然数字排序**：`1 / 2 / 3 / 10 / 11` 按数字大小排，不是按字符排，
  `001` 与 `Page 1` 这类写法也能对上
- 扩展名和实际内容不符时按**文件头魔数**兜底识别（把 RAR 改名成 `.cbz` 照样能读）

### 导入与扫描

- 通过 Storage Access Framework 授权文件夹，可授权多个，自动扫描
- **扫描是增量的**：按「路径 + 大小 + 修改时间」判定新增 / 修改 / 删除 / 跳过，
  没变过的文件不会重复解析
- 后台执行，显示进度，随时可取消，不阻塞界面
- **封面生成与扫描分离**：扫描只负责入库，封面在后台慢慢补 ——
  所以打开应用立刻就能看到书架，不用等几百个封面全部生成完
- 新增「文件健康检查」：逐个打开归档读一遍中央目录，找出打不开、没有图片页、
  页数与库里记录对不上的漫画。**只报告，不自动改数据**

### 阅读

- 三种模式：**单页 / 双页 / 纵向连续**，单双页一律从左向右翻
- 缩放：双击、双指、拖动，四种适配（适应屏幕 / 适应宽度 / 适应高度 / 原始比例）
- **按原图分辨率渲染**：放大时只解当前可见的那一块（`BitmapRegionDecoder` 区域解码），
  不为了放大而把整页按高倍率重新解码一遍
- **超长条漫分块只为省内存**：竖屏一屏装不下的长图按滚动窗口分块，
  分块不降分辨率 —— 目的是别让一张几千万像素的图把内存撑爆
- 坏页可以「重试」或「跳过」，单页损坏不会让整本读不下去；
  打开失败的提示按原因分流（加密 / 权限失效 / 文件消失 / 结构损坏 / 格式不符），
  不是一句笼统的「文件可能已损坏」
- 阅读页菜单：屏幕旋转 / 亮度 / 渲染模式 / 音量键翻页 / 屏幕常亮 / 显示页码
- **PDF 按屏幕像素重新绘制**：PDF 的页面单位是「点」，A4 只有 595×842，
  直接按原始尺寸渲染会糊；放大到几倍都不糊是因为每次都按当前屏幕像素重新光栅化
- **EPUB 支持目录跳转**，也可以直接输入页码直达；文字章节跟随阅读器背景与配色，
  不会在深色背景上铺一张白纸
- 阅读页默认不自动沉浸，点一下才全屏

### 书架

- 四种视图：**全部 / 收藏 / 文件夹 / 标签**
  - 后两种以「手机文件夹」「标签」为单位聚合成书架文件夹，点进去再看
  - 封面默认取组内最新入库的那本，**长按可改成组内任意一本**
- 四种排版：2 列网格 / 3 列网格 / 小封面列表 / 大封面列表
- 视图、排版、排序都会记住，重启不回到默认
- **长按批量选择**：批量收藏 / 取消收藏 / 打标签 / 移除。
  「收藏 / 取消收藏」按当前状态合成一个按钮，不会出现「已收藏的项上还写着收藏」
- **移除有 5 秒撤销窗口**：先快照整条记录与标签关系，5 秒内点撤销就还原。
  不做无限期软删除 —— 那样数据只会越来越脏
- 右下角「继续阅读」悬浮窗直达上次位置，**左滑即关**（本次会话内不再出现）
- 长列表右侧浮现细滚动条，可拖动定位；不在顶部时还有「返回顶部」按钮

### 标签与收藏

- 标签完全由用户创建，支持批量添加 / 移除
- **批量写入按差集语义**：只加新勾上的、只摘取消勾选的。
  用户没在对话框里见过的标签一行都不动 —— 否则给 A、B 打标签会顺手把 A 上原有的标签一起摘掉
- 标签页两列卡片，一屏能看到约两倍的标签；标签可改名字与颜色
- **收藏是独立概念，不是标签**：标签页顶部单独一块区域放「收藏」入口，
  没有标签的时候它也不会跟着消失

### 进度与统计

- 自动保存页码与百分比，下次接着看
- **阅读偏好和翻页进度分开落库**：翻页只写位置，
  模式 / 适配这些只在用户显式改动时才写 —— 否则「读过的每一本都被固化成当时的设置」，
  设置页里的默认值就永远不生效了
- 阅读统计：累计时长、翻页数，以及阅读历史（按时间倒序，点开即读，长按进详情）
- 搜索标题 / 作者 / 标签 / 文件名，支持模糊与分词
- 8 种排序方式

### 数据备份与恢复

换手机不等于丢失阅读数据。

- **只备份应用数据**（漫画信息、阅读进度、阅读统计、标签、收藏、书架封面、设置），
  不含漫画原文件，备份体积很小
- 格式为自定义 `.gaze-backup` 文件（本质是 ZIP，内部是可读的 manifest / database / settings），
  可以直接从文件管理器「打开方式」选中 Gaze 恢复
- **可指定备份文件夹**：选定一个目录后一键导出，不用每次过系统文件选择器
- **自动备份**：可选按天 / 周 / 月，只在打开应用时检查是否到点，不做后台常驻
  （国产 ROM 会掐后台，常驻任务反而不可信）。只保留最近几份，
  且**只轮转自动备份**（认 `gaze-auto-` 前缀），手动导出的一份都不动
- **历史备份**：列出备份文件夹里的全部备份（时间、文件名、大小），直接选一份恢复
- **文件匹配**：核对某个备份里的漫画本地还剩几本，口径与恢复时完全一致
- **按内容匹配而不是按路径**：恢复时走「内容指纹 → 采样哈希 → 文件名 + 大小」三级匹配，
  换设备后即使文件位置全变了也能自动对上；实在找不到的标记出来，历史数据保留，可手动重新定位

### 外观与设置

- 主题：跟随系统 / 浅色 / 深色
- **7 套纸张主题**：宣纸 / 米黄 / 灰蓝 / 青瓷 / 藕粉 / 石墨 / 紫檀 ——
  每套都是「一种纸 + 一种墨 + 一个强调色」的完整组合，换的不只是底色
- **自定义主色**：挑一个颜色，用 HSL 派生整套纸色 / 墨色 / 强调色。
  **强调色跟着主题一起走** —— 否则会出现「青瓷纸配朱红点」这种互相打架的搭配
- **阅读器背景独立设置**（黑 / 深灰 / 白），和系统主题解耦：
  应用用浅色、阅读页用黑底，是两种需求
- 设置是一个主页 + 七个二级页（外观 / 阅读 / 书架 / 媒体库 / 文件名解析 / 数据备份 / 关于），
  每行右侧直接显示当前值

### 界面

Editorial / Manga Editorial 视觉语言：克制的排版、低饱和的纸墨色、强调色只用在少数几个地方。
没有社交、没有推荐、没有广告。

渲染提供「优化渲染 / 传统渲染」两档：优化渲染走分块解码与按需加载，省内存；
传统渲染一次解整页，兼容个别解码异常的图片。

## 项目结构

```
Gaze/
├── app/src/main/java/com/gaze/reader/
│   ├── GazeApp.kt       Application + 依赖容器
│   ├── MainActivity.kt  单 Activity，处理「用 Gaze 打开」与分享导入
│   ├── archive/         归档读取层（ZIP / RAR / 7Z / TAR）+ 页面提供者 + PDF / EPUB
│   ├── backup/          备份导出与恢复
│   ├── core/            自然排序、文件名解析、格式定义、枚举
│   ├── data/            Room 数据库、仓库层、DataStore 设置
│   ├── domain/          标签配色、内容指纹、SAF 路径显示
│   ├── image/           图片解码、封面缓存
│   ├── scan/            增量扫描、封面生成、SAF 权限
│   └── ui/              Compose 界面（导航 / 组件 / 页面 / 主题）
├── assets/              README 顶部那张图标
├── tools/               图标生成脚本（Python，生成后手动放进 assets/ 与 res/）
└── gradle/              Gradle Wrapper
```

归档层只回答两个问题：「这本书里有哪些页」「某一页的流怎么拿到」。
上层（阅读器、扫描器、封面生成、健康检查）只认识 `PageProvider` 这一个接口，
所以新增一种格式 = 加一个实现 + 工厂里一条分支，不用动上层任何代码。

## 构建

需要 JDK 17 与 Android SDK（compileSdk 36 / build-tools 35.0.0）。

```bash
export JAVA_HOME="<JDK 17 路径>"
export ANDROID_HOME="<Android SDK 路径>"
./gradlew assembleRelease
```

Windows 下用 `gradlew.bat`。首次构建会通过 Gradle Wrapper 自动下载 Gradle 8.13
（发行包地址已指向腾讯云镜像，国内拉取不必再等）。

产物：`app/build/outputs/apk/release/app-release.apk`

仓库**不包含**任何签名密钥，未配置签名时也能正常构建（产出未签名 APK）。若你要发布自己的构建，
请生成自己的密钥库并在仓库根目录创建 `keystore.properties`（已在 `.gitignore` 中忽略）：

```properties
storeFile=../path/to/my-release.jks
storePassword=<你的密码>
keyAlias=my-key
keyPassword=<你的密码>
```

> 换密钥意味着已安装的旧版本无法覆盖升级，用户必须先卸载。自己从源码构建的话，这件事只影响你自己。

## 隐私

**Gaze 不收集任何数据，也没有任何联网能力。**

- 应用未声明 `INTERNET` 权限，构建时还显式删掉了依赖可能传递进来的
  `INTERNET` 与 `ACCESS_NETWORK_STATE`，从系统层面就无法发起网络请求
- 没有账号体系、没有统计 SDK、没有广告、没有崩溃上报
- 所有漫画、阅读进度、阅读统计、标签、设置都只保存在设备本地
- 唯一的文件访问通过 Android SAF 授权，你可以随时在设置里撤销

装完之后可以自己核对：`aapt2 dump badging Gaze.apk`。权限表里只会看到一条
`com.gaze.reader.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION` ——
AndroidX 自动加的**应用私有**签名级权限，用来声明内部广播不对外导出。
它不是系统权限，也不会出现在系统设置的「应用权限」列表里。
**这条不是网络权限，权限表里没有 `INTERNET`，也没有 `ACCESS_NETWORK_STATE`。**
